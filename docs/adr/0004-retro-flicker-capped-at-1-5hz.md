# 复古动效的闪烁频率压在 1.5Hz

Web 2000 / Win98 的跑马灯、闪烁、欢迎动画全部实现且默认开启，但闪烁频率固定 1.5Hz，
不使用浏览器 `<blink>` 的默认节奏。

**为什么**：WCAG 2.3.1 的医学阈值是「每秒 3 次闪光」，而早期网页 `<blink>` 的实际节奏就在
1~2Hz 这个区间——1.5Hz 既是时代 authentic 的，又稳稳落在安全线内。这不是为了还原度而牺牲
安全，是同一件事的正确实现方式。

**Considered Options**

- 用 `<blink>` 或更快节奏：还原度并不增加（肉眼分不出 2Hz 和 4Hz 哪个更「复古」），风险
  却是实打实的。
- 砍掉闪烁：Web 2000 最标志性的动态特征消失，与本项目「完全自由、要还原度」的定位冲突。

**Consequences**

所有动效仍必须尊重 `prefers-reduced-motion`，系统设置优先于这里的一切默认值。这个频率上限
属于风格自己的 `config.ts`，复古风格可以声称自己「遵守了本项目的动效安全约定」，
但不得自行提高。
