# 复古动效的闪烁频率压在 1.5Hz

Web 2000 / Win98 的跑马灯、闪烁、欢迎动画全部实现且默认开启，但单个闪烁元素不超过 1.5Hz，
不使用浏览器 `<blink>` 的默认节奏。

**为什么**：WCAG 2.3.1 规定页面不能出现任意一秒超过三次且达到相关亮度／红色阈值的闪光。
项目把单个复古元素的闪烁压到 1.5Hz，保留风格特征，同时给合成后的页面效果留出检查余地。
这个频率只是实现上限，不单独构成对页面无障碍或医学安全的证明。

**Considered Options**

- 用 `<blink>` 或更快节奏：无法精确控制或验证页面整体的闪光次数与阈值。
- 砍掉闪烁：Web 2000 最标志性的动态特征消失，与本项目「完全自由、要还原度」的定位冲突。

**Consequences**

所有动效仍必须尊重 `prefers-reduced-motion`，系统设置优先于这里的一切默认值。这个频率上限
属于风格自己的 `config.ts`，不得自行提高；还要检查多个元素同时闪烁时页面整体是否满足
WCAG 2.3.1。
