# Claude · 设计卡

> 风格 id：`claude`。本卡是这套风格与 T23 视觉复核逐项对照的依据，先于 CSS 写成。
> 参考原型：**Anthropic / Claude 自己的视觉语言**（奶油纸面 `#f0eee6`、近黑暖墨、单一珊瑚陶土色
> 强调色）与**书籍排版**（衬线展示字、细线分栏、大留白）的交叉——不是「又一套暖色主题」。

## 1. 参考与氛围

- **可辨识的参考**：翻开一本排印讲究的书——奶油色纸、衬线标题、靠**细线与留白**分栏而不靠
  色块；以及 Claude 品牌那一屏：暖白底、近黑字、一处陶土色。看到这屏的人应当认出
  「这是一本被翻开来的书 / 这是 Claude 的样子」，而不是「某个 2048 仿品」或「Classic 换了个底」。
- **气质**：安静、有礼、印刷感。层级靠**明度与细线**，不靠投影、不靠饱和色、不靠玻璃。
- **唯一允许的装饰**：板面外那一圈细线（纸被放在桌面上的边界），加上方块合并时按更缓的
  曲线走过的一次位移（T21 落地，时长由本风格令牌给出）。除此之外不做装饰。
- **与另两套的分界**（§9 有一张灰度指纹表，去掉颜色之后也分得开）：
  - Classic 是**全扁平 + 全填充**：深棕底板、深棕控件、整条暖棕阶梯；
  - Material 是**白卡 + 投影 + 色调阶梯**：层级几乎全部由 elevation 说出；
  - Claude 是**纸 + 细线 + 衬线**：控件**不填色**（只描边），板面**不投影**（只描一圈线），
    全壳唯一一处实色填充是「被选中的控件」那一块陶土色。

## 2. 色彩角色

全部色值由 `tokens.css` 提供，`board.css` 只负责把色值贴到固定 DOM 上。

| 空格（纸上的暖灰凹陷） | `--cell-bg` | `#cec4ae` |
| 障碍（Walls 模式的四格固定障碍） | `--wall-bg` | `#3b4750` |

| 控件字（描边按钮） | `--control-ink` | `#26241f` |

**一个暖色强调色，用在三个地方**：选中控件、焦点环、以及「触到本模式目标值」的那一档方块
（第 11 档）。除此之外全壳不含第二块暖色填充——这也是「暖色层级可被识别」的关键：暖色在这
套风格里是**稀缺品**，出现就代表一件事（此刻被选中 / 此刻有焦点 / 你到了目标）。

### 方块阶梯：纸 → 暖灰 → 墨，目标档点亮一次

阶梯按**色档**命名（T13 起），不按数值：档位是「在本模式目标前的相对进度」，由
`components/ValueLadder.ts` 从模式已声明的 `spawnValues` + `target` + `mergeFamily` 推出来，
所以第 11 档在经典模式是 2048、在斐波那契是 2584、在大棋盘是 4096。

| 档 | 底色 | 上面的字 | 对比度 |
| --- | --- | --- | --- |
| 1 | `#f7f4ec` | `--ink` | 14.11:1 |
| 2 | `#efe9db` | `--ink` | 12.81:1 |
| 3 | `#e3dac6` | `--ink` | 11.16:1 |
| 4 | `#d3c8ae` | `--ink` | 9.33:1 |
| 5 | `#c1b694` | `--ink` | 7.67:1 |
| 6 | `#a89e8d` | `--ink` | 5.86:1 |
| 7 | `#74685a` | `--ink-bright` | 5.16:1 |
| 8 | `#5c534a` | `--ink-bright` | 7.15:1 |
| 9 | `#463e37` | `--ink-bright` | 9.96:1 |
| 10 | `#2e2925` | `--ink-bright` | 13.67:1 |
| 11 | `#a8482b` | `--ink-bright` | 5.50:1 |
| 超出本模式目标值 | `#1d1a17` | `--ink-bright` | 16.46:1 |

三处要写进复核结论的取舍：

1. **深浅字在第 6 / 7 档之间断开一次**，因为两种字色都过不了 4.5:1 的死区在相对亮度
   0.174～0.254 之间（实测口径：`--ink` 亮度 0.0175、`--ink-bright` 亮度 0.95，反解即得）。
   断口的代价是相邻亮度比 2.42，比 Classic 的 3.1（4→8）小、比 Material 的 1.54 大。
   第 7 档（5.16:1）是本套 12 档里最紧的一档，**复核先看它**。
2. **第 11 档是全阶梯唯一一次变亮**（相邻亮度比 0.18）：它不是「更暗的一档」，是「到了」。
   唯一的暖色填充落在这里，于是「我快到目标了」在颜色上只有一种说法。`--tile-beyond` 回到
   墨色 `#1d1a17`：过了目标就不再是里程碑，只是继续变深。
3. **前 6 档与空格的关系会翻转**：第 1～3 档比空格亮，第 4～5 档比空格暗（这是「低档几乎
   就是纸」的必然结果）。这一对**不承载**「哪一格有方块」——方块永远带数字、空格永远不带，
   判据是数字本身；1.5:1 上下的明度关系与 Classic（1.41:1）、Material（1.51:1）同量级，
   按装饰层级成立，不按指示器阈值成立（同 Classic 设计卡 §9 收口的那条 exclusion）。

**障碍（`#3b4750`）**：一块**冷灰蓝**，刻意落在上面这条暖色阶梯之外。判同 Classic / Material：
障碍必须同时与「可玩空格」和「数值方块」分得开，而方块永远带数字、障碍永远不带。
实测 vs 空格 `#cec4ae` = **5.51:1**，按非文字指示器的 3:1 走（Walls 模式里这一对承载
「哪些格能放方块」）。

**新风格的 `tokens.css` 必须声明 `--wall-bg`**：`board.css` 的 `[data-cell='wall']` 直接读这个
变量，而棋盘固定结构不属于任何一套风格（ADR-0002），所以它是每一套风格都要交的色值。
哪一套漏了它，那条声明在计算值时无效，`background` 退回 `transparent`——墙会变回**四个看不
见的洞**，也就是 T07 修掉的那个 bug，而且浏览器一个字都不报。

## 3. 字体角色

- **展示**：标题「2048」、面板数值、方块数值 → **Playfair Display**（didone 展示衬线）。
  选它的理由有两条：① 它的高对比笔画是「书页」这一层最直接的信号，与另两套的 grotesk
  （Inter / Roboto Flex）在任何回退栈里都不会混；② 它是自托管字库里唯一带 `lnum` 特性的
  衬线（读 `public/fonts/playfair-display/*.woff2` 解出来看过：特性里有 `lnum` / `zero` /
  `case` / `frac`），所以方块数字可以锁定**齐线数字**——didone 家族默认交付的多是旧式数字，
  下落与上升会让一列方块高低不齐，而这是方块上最不能让步的一件事。Fraunces 的 subset 里
  一个特性都没有（同一个探针看过），所以它反倒给不了这个保证。
- **正文**：界面标签、按钮、说明 → **Source Sans 3**（人文无衬线，400 / 600）。
  刻意不用 Inter 或 Roboto Flex：那两套已经被 Classic / Material 占了，第三套再用就把
  「三套风格三种字体」这件事打穿了。
- **方块数值**：`--tile-font-family: var(--font-display)` + `--tile-font-weight: 700`。
  Playfair 的细笔画在长数值上会发虚（6～9 位、0.2 倍格边长，桌面约 20px、窄屏更小），
  所以方块的字重抬到 700——把笔画撑住是这一档字号下唯一的办法；标题反而只用 600，
  大字号下 700 会过分强硬。数字等宽照旧由 `board.css` 的 `tabular-nums` 声明，
  **但 Playfair 的 subset 不带 `tnum`**（同一个探针看过：只有 `lnum` / `zero` / `case` /
  `frac`），所以合并前后位数变化时方块数字不是等宽的——影响是数字在格内重新居中，
  方块本身由 `board.css` 绝对定位、宽高与数字无关，不是错位。这一条记在这里，
  免得 T23 拿「数字为什么不等宽」当缺陷翻案。
- **回退**：同字形类别（ADR-0005）——衬线挂 `var(--fallback-display-serif)`（Georgia /
  Times New Roman），正文挂 `var(--fallback-humanist)`（Frutiger / Segoe UI）。缺字时整套
  风格在**同一字形类别内**降级：标题与方块数字退成 Georgia 仍是衬线，正文退成 Segoe UI
  仍是无衬线，风格不散。第二道机制是 `data-font-state`（ADR-0005 / `fontState.ts`）：
  切到本风格时按当前风格实际在用的本地字体重新观察，404 立刻落 `fallback`。
- 数字永远是西文：`unicode-range` 只有 latin 子集，中文不会触发本地字体请求。
  **顺带一个诚实的前提**：界面上几乎全部文案是中文，由系统字体渲染，所以正文字体（Source
  Sans 3）在多数文案上并不可见——它的职责是声明的兜底栈与「将来出现西文时不落到 Inter 上」。
  这一套风格的排版识别度主要由**衬线**（标题、面板数值、方块数字）承担，不是由正文承担。

## 4. 布局与密度

- 单列居中：标题 → 分数 / 目标 / 最高方块 → 风格选择 → 棋盘 → 方向按钮与操作提示。
  骨架与 Classic / Material **逐字节一致**（ADR-0002：棋盘固定结构；外壳骨架也保持一份）。
- **密度比另两套都松**：控件内边距 0.75rem × 1.75rem（Classic 0.625 × 1.25、
  Material 0.625 × 1.5）、面板内边距 0.875rem × 1.5rem（Classic 0.5 × 0.875、
  Material 0.75 × 1）、终局面板内边距 1.75rem（Classic 1rem、Material 1.5rem）。
  节奏按 4px 网格取值；这是三套风格在**布局**上唯一能分开的地方（外壳的 gap / padding 由
  Tailwind 统一持有，见 §5）。
- 面板不填色，只在上方压一条 1px 细线：于是「分数 / 目标 / 最高方块」读起来是**同一张纸上
  的三栏**，而不是三张卡片。数值用 Playfair 600，与标题同族不同字号，全屏只有它和方块数字
  是衬线。
- 棋盘尺寸仍由模式数据与 `BoardLayout.ts` 决定，格子边长、间距、内边距只有一份数值。

## 5. 棋盘与外壳的区别处理

- **棋盘层**（`board.css`，不用任何 Tailwind utility）：固定 DOM 结构 + `boardOverlay` /
  `tileOverlay` 两个装饰插槽。
  - 板面是**一张比页面亮一档的纸**（`--board: #faf8f2`），外面描一圈 `--rule` 细线
    （`outline`，不进布局——见下）。板面 vs 页面只有 1.09 的明度关系，边界全靠那圈线说；
    Material 靠投影，Classic 靠一块深色底板，这是三者在棋盘上最直接的分岔。
  - 为什么用 `outline` 而不是 `border`：`border` 会让棋盘盒子大出一像素，而 `.board__cells`
    按 `padding` 盒绝对定位（`board.css` 的 `inset: var(--board-padding)`），多一像素边框
    会把格子层整体推移，Classic 的逐字节比对就多出 2px 的漂移。`outline` 画在 border box
    之外，**不进布局**，也不影响 `touch-action` 与指针捕获。
  - 空格是暖灰凹陷（`--cell-bg`），与板面差 1.63 的明度；方块圆角 2px、板面圆角 4px，
    比 Classic（6 / 6）紧、比 Material（16 / 12）更紧——印刷品的角是接近直角的。
  - 方块字族由 `--tile-font-family` 给出（T15 往 `board.css` 加的钩子，默认
    `var(--font-body)`，所以 Classic / Material 渲染不变）。
- **外壳**（Tailwind utility + 本风格 `styles.css` 的语义类）：管页面底色、文字色、
  间距与响应式。外壳的**布局**（`grid place-items-center px-4 py-8`、`gap-4`）由 `App.tsx`
  统一持有，不属于任何风格；风格拥有外壳的**观感**。
- 两个装饰插槽在 Classic、Material 与 Claude **都是空的**（`config.ts` 里返回 null）：
  Claude 的装饰是**排印与细线**，全部由 CSS 表达，不需要 DOM 节点。真需要结构装饰的风格
  （Aero 的 gloss、Terminal 的扫描线）届时只改 `config.ts` 的返回值，棋盘与引擎都不动。
  插槽机制由 `Board.tsx` 从风格配置解构后渲染，不写死成 null——所以这条边界现在就是活的。

## 6. 独有装饰与动效

- **位移**：150ms + 三套风格共用的 `ease-out`；安静感由纸色、衬线
  字体与无投影层级表达，避免靠长时长拖慢每一步。
- **生成只淡入**：`--tile-spawn-duration: 140ms`。
- **合并与胜利**：两段 CSS scale 过渡合计 80ms，在接近落点时启动；React 提交回落阶段时增加的帧间隔会延长浏览器观察到的总时长。不透明胜利面板盖住棋盘，标题轻微淡入。
- **板面外那一圈细线**是这套风格唯一的静态装饰，颜色 `--rule`（装饰关系，不承载信息：
  板面与页面的明度差只有 1.09，但「棋盘在哪里」由格子层自己说清）。
- `prefers-reduced-motion: reduce` 下 `--tile-move-duration` / `--tile-spawn-duration` 归零，
  方块直接到位；标题缩放停止、只保留淡入（SPEC §3.2）。生成与合并描一圈 `--focus`，
  胜利面板仍不透明覆盖棋盘。
- **本风格不用**：渐变、`box-shadow` 投影、`filter`、扫描线、网格纹理、emoji 当装饰、
  把方块做成 `<button>`、用 `opacity` 调文字明度。

## 7. 禁用的通用样式

- 禁 Tailwind 调色板色值出现在棋盘与方块层（连 `bg-slate-100` 都不行）；也禁出现在外壳——
  本风格所有色值都在 `tokens.css` 里。
- 禁渐变背景、禁 `filter`、禁 emoji 当装饰。
- 禁把方块做成 `<button>`：方块是状态不是控件，交互归棋盘根元素。
- 禁在 `src/game/` 里出现任何本风格的引用（ADR-0001）。
- 禁第二块暖色填充：`--control-bg-selected`（选中控件）、`--focus`（焦点环）、
  `--tile-11`（目标档）三处之外，任何实底都必须是纸面 / 暖灰 / 墨。
- 禁 `border` 画控件或板面的边（会改盒子尺寸，见 §5）；用 `outline`，它同时让对比度闸门的
  `ring` 探针读得到这条边。

## 8. 手机窄屏策略

- 视口 ≤ 520px 时格子边长收缩（`BoardLayout.fitCellSize`），间距与圆角同比缩小。
  圆角是**固定 px**（4 / 2），不像字号那样跟着格子缩：这一套的角接近直角，跟着缩只会让
  宽屏与窄屏看起来像两套风格。
- 信息条从横排改为竖排堆叠，分数不被裁切（外壳的 `flex-wrap` 承担，风格不改骨架）。
- 风格选择器在窄屏与信息条同宽、按文字宽度折行（`flex-auto` + `flex-wrap`）：
  三套风格（Classic / Material / Claude）在 `max-w-md` 里放不进一行，自动折成两行，
  不会把棋盘挤出屏外。
- 触屏操作归 T10：方向按钮在 `(pointer: coarse)` 下进场，复用 `.control` 的描边与焦点环。

## 9. 对比度与无障碍

- 正文与小字按 4.5:1 走，方块数值也按 4.5:1 走——**没有任何一档依赖大字 3:1 口径**，
  包括一位数的第一档（14.11:1）。「字号随位数变化」因此与本风格的对比度结论完全解耦。
  非文字指示器（控件描边、焦点环、选中环、障碍）按 3:1 走。
- **T14 起每一对都写明口径（`basis`）、测量场景（`scene`）与探针（`probe`）**：口径是
  regular / large / non-text 三选一，且与 `minimum` 必须自洽（4.5 / 3 / 3）——「哪一对靠大字
  豁免」因此是表上的一个字段，而不是谁脑子里的一句话。场景是 start / run / walls；
  探针是那一对在页面上真正被量到的元素，浏览器那一层按它读计算样式。声明对了不等于渲染
  对了——选择器失效、漏了 `data-style` 这类事，只有那一层抓得到。
- **控件描边为什么入表**：这一套的控件不填色（底就是纸面），「这里有个按钮」由那一圈 1px
  说出，所以它是 1.4.11 口径下识别组件所必需的视觉信息，按非文字指示器 3:1 走
  （实测 `#857c6d` on `#f0eee6` = **3.54:1**）。入表的条件之一是闸门的 `ring` 探针读得到它
  ——所以描边用 `outline` 而不是 `border`（见 §5 / §7）。
- **焦点环是暖色的**（`--focus: #a8482b` on `--page` = **4.98:1**，非文字口径）：
  全壳只有焦点与被选中用这块陶土色，于是「焦点在哪」自带一个颜色提示。
- **选中环那一对**：`board.css` 的 `[data-selected='true']` 用带 spread 的 box-shadow 画在
  border box 外侧、落在 `--cell-bg` 上（BOARD_GAP 远宽于那 3px 的环）。本风格
  `#a8482b` on `#cec4ae` = **3.34:1**，非文字口径。
- **空格 vs 板面（1.63）与板面 vs 页面（1.09）不在表内**，理由同 Classic 设计卡 §9：那是
  装饰性的明度层级。真正承载信息的是「方块 vs 空格」（由数字承担，见 §2 第 3 条）与
  「障碍 vs 可玩空格」（5.51:1，表内）。
- **怎么在去掉颜色之后认出这是 Claude**（灰度指纹，相对亮度 L，全部可由 `tokens.css` 复算）：

  | 表面 | Classic | Material | Claude |
  | --- | --- | --- | --- |

## 10. 成就祝贺（toast）

解锁一个成就时浮出的一条短提示（ADR-0007；词汇见 `CONTEXT.md` 的 Toast 词条）。它是
**每套风格自己实现的呈现插槽**（ADR-0002），所以这一节是本套的长相与消失表现，
而「什么时候该有一条」全在 store。

**位置与堆叠**

- `position: fixed`，贴视口右上角：`top: 0.75rem`、`left/right: 0.75rem`，向右对齐。
  **不进文档流**——流内的一条提示会把棋盘整体推下去，正在打的一局当场错位。
- 宽 `min(22rem, calc(100vw - 1.5rem))`；最多三条，**最新的一条在最上**，自第二条起
  向下排（gap `0.5rem`）。第四条到达时丢最旧（单局成就规格的架构决策 6）。
- **为什么是右上**：棋盘在页面正中、方向按钮在它正下方（触摸设备上是一整行），
  右上是这两处之外、且在手机与桌面都留得出空的地方。三条 × 约 `3.25rem` + 间距
  ≈ `11rem`，仍落在棋盘上沿之上。
- 容器 `pointer-events: none`、每张卡片 `pointer-events: auto`：卡片**之外**的点击
  穿透到下面的控件，所以它不拦操作。

**结构**

`div.toast-stack > div.toast[role=status][tabindex=0]`，里面两句：`「解锁成就：」` 与成就名
（一次跃迁里满足几个就写几个，用「、」连起来——一条提示，不是每个成就一条）。
容器与每一条都用 `div` 而不是 `ul`/`li`：这些是**状态消息**，不是「一列东西」；`role="status"` 会把 `listitem` 覆盖掉，剩下的那个 `ul` 在无障碍树里就是一份空列表。

**长相：一张撕下来的纸，不是一张卡片**

本套的面板不填色，`styles.css` 里的 `.panel` 只有一条 1px 细线压在顶上。toast 沿用同一条
语言：**底色就是纸面 `--page`（不透明，压在别的内容上也读得清），上面一条 `--rule` 细线**，
圆角 3px（与控件同尺，见 §5）。没有投影——本套全壳零投影，层级靠明度与细线（§6 / §2）。

| 用途 | 令牌 | 色值 | 对比度 |
| --- | --- | --- | --- |
| 纸面底 | `--page` | `#f0eee6` | — |
| 顶线（装饰） | `--rule` | `#b8af9b` | 不承载信息（与板面那一圈同一条理由，§9） |
| 成就名 | `--ink` | `#26241f` | 13.35:1 |
| 前缀「解锁成就：」 | `--ink-variant` | `#5d584e` | 6.08:1 |

**字体**：前缀用正文 `--font-body`（Source Sans 3）400；**成就名用展示衬线
`--font-display`（Playfair Display）600**——这是全壳除标题、面板数值与方块数字之外，
衬线第四次出现，正是本套「用排印说身份」的地方（§3）。字号与正文同档，不放大：
它是一条标注，不是标题。

**动效**

- **进**：`opacity 0→1`，**180ms** + `ease-out`（与全局同一条曲线，§6）。**不做位移**——
  本套的安静感来自「不加动作」，位移留给方块（§6 只说棋盘层的位移）。
- **停**：进场结束之后可见 **5000ms**；指针悬停在这一条上或焦点落在它里面时**暂停计时**，
  移开 / 失焦接着走剩下的时间（不重新计满）。
- **出**：`opacity 1→0`，**200ms**，动画结束再从栈里移除。
- **`prefers-reduced-motion: reduce`**：进 / 出时长归 0（直接出现、直接消失），
  色值、细线与字体一个字段都不变——降级的是「怎么动」，不是「长什么样」。

**无障碍**

- `role="status"`（隐式 polite + atomic）：每条只播报一次，且整条在场期间一直留在
  无障碍树里，读屏用户可以回头再读。
- `tabindex="0"` 让它进 Tab 顺序——「焦点在内时暂停」正是靠它成立的。但**从不自动抢焦点**：
  解锁不改变 `document.activeElement`，方向键照旧归棋盘。
- 焦点环用暖色 3px + 外移 2px（`outline: 3px solid var(--focus); outline-offset: 2px`），
  与控件、板面同一条（§9 的 4.98:1）——本套全壳只有焦点与被选中用那块陶土色。

**约束核对**：不遮棋盘（贴顶、最多三条）· 不压方向按钮（在页尾，离顶部最远）·
不拦操作（容器穿透）· 三条同屏仍可读（每条一行、最长两行，名字之间顿号分隔）·
纸面底不透明，压在风格选择器等控件上也读得清。
