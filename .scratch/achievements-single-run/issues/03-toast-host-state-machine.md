# 03: 宿主状态机：跃迁、收回、堆叠

**What to build:** 「什么时候该有一条祝贺」这件事的状态机，住在 store 里（因此不需要浏览器就能
验证）。当前解锁集合从对局状态**派生**：锁定 → 解锁的那一次跃迁产生一条祝贺，一次跃迁里满足
多个成就合并成一条；撤销把不再成立的解锁收回，重新达成算新的一次跃迁；同时最多三条在场，
第四条到达时丢最旧。从存档恢复一局时先建立**静默基线**——不补放祝贺，但集合与恢复前一致。
唯一的例外是风格旅行者：它的计数故意不跟撤销回退，所以它解锁后本局收不回（理由写在 ADR-0007）。
